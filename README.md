## **SAND: Sub-Annual Net for Land Dynamics** 🌍📡  

This repository contains the official implementation of **Sub-Annual Net for Land Dynamics (SAND)**, a Transformer-based autoregressive classifier for fine-scale **sub-annual land cover mapping** using time-series remote sensing imagery.  

SAND overcomes the limitations of traditional land cover classification methods that assume no intra-annual changes, providing **more detailed temporal characterization** and enabling the detection of short-term land transitions. Our experiments across multiple cities demonstrate the effectiveness of SAND in capturing **high-resolution land dynamics**.

## **Usage** 🚀  

### **Training** 🏋️‍♂️  
To train the model, simply run:  
```bash
python train.py
```

### **Testing** 🧪  
To evaluate the trained model:  
```bash
python test.py
```

## **Results** 🏆  

SAND has been tested on multiple cities worldwide, demonstrating **high accuracy in detecting intra-annual land transitions**. Compared to traditional annual-scale methods, SAND achieves **better temporal precision** and effectively identifies subtle land cover changes within a year.  

![image](https://github.com/user-attachments/assets/17977fba-6d25-43e1-80ec-d616cdd8171b)


📌 **Key Features:**  
✅ **Transformer-based architecture** for temporal sequence modeling  
✅ **Autoregressive decoding** to capture land transitions  
✅ **High-resolution intra-annual land cover mapping**
